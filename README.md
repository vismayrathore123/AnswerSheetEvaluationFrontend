# Answer Sheet Evaluator – UI test (React only)

## Run
    npm install
    npm run dev
Open http://localhost:5173

## Use
1. Click "Upload question paper" (PDF or image).
2. Click "Upload answer copies" (one or many PDF / JPG / PNG; one file = one copy, file name = barcode).
3. Pick a tool (pen, tick, cross, highlighter, comment, eraser) and mark on the copy.
4. Type marks in the table at the bottom. Total is automatic.
5. Submit marks. The data that will go to the API later is shown.
